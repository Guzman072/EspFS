# EspFS

基於 **ESP32** 的雙輪差速無線控制專案，整合 **FlySky FS-i6X** 遙控系統與 **ZLTECH ZLAC8015D** 雙輪轂伺服驅動器。

## 1. 硬體清單
* **主控板**：ESP32 開發板 + 擴展板（跳線帽設定於 5V）
* **遙控設備**：FlySky FS-i6X 遙控器 + FS-iA6B 接收器（使用 i-BUS 協定）
* **通訊轉換**：TTL 轉 RS485 自動流向控制模組
* **馬達驅動**：ZLTECH ZLAC8015D 雙通道輪轂伺服驅動器

## 2. 腳位接線表（Pinout）

### A. 接收器（FS-iA6B `i-BUS SERVO` 排針 ➔ ESP32 擴展板）
* **訊號 (`S`)** ➔ `GPIO 18` (`D18` / UART1 RX) *(註：5V 訊號建議串接 1kΩ 電阻保護)*
* **電源 (`+`)** ➔ `5V`
* **接地 (`-`)** ➔ `GND`

### B. RS485 模組 ➔ ESP32 擴展板（UART2）
* **`TXD`** ➔ `GPIO 17` (`D17`)
* **`RXD`** ➔ `GPIO 16` (`D16`)
* **`VCC`** ➔ `3V` (3.3V)
* **`GND`** ➔ `GND`

### C. RS485 模組 ➔ ZLAC8015D 驅動器
* **`D+/A`** ➔ 驅動器 `485A`
* **`D-/B`** ➔ 驅動器 `485B`
* **`GND`** ➔ 驅動器 `GND`

## 3. 供電安全規範
* **開發測試**：僅使用 **ESP32 開發板本體的 Type-C 接口** 連接電腦供電與傳輸資料（勿接擴展板底部的 USB 孔）。
* **擴展板 DC 座**：耐壓為 **DC 6.5V–12V**（嚴禁接入 19V 變壓器）。
* **ZLAC8015D 驅動器**：需獨立接入 **24V–48V DC** 電源。
